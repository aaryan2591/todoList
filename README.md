# 🍽️ Restaurant Page

A multi-section restaurant website — Home, Menu, and About — built 
with webpack to practice bundling, modules, and dynamically 
rendering content without page reloads.

🔗 **[Live Demo](https://aaryan2591.github.io/restaurant-page/)**

<img width="800" alt="Restaurant home page" src="https://github.com/user-attachments/assets/226ed53d-98dc-4fe5-9e53-ab93fc593cb3" />


## Features

- Home, Menu, and About sections
- Content rendered dynamically via JavaScript (single-page feel, no reloads)
- Bundled and built with Webpack

## Built with

- HTML
- CSS
- JavaScript
- Webpack (webpack-dev-server, html-webpack-plugin, css-loader, html-loader)

## What I practiced

- Setting up a Webpack build pipeline
- Organizing code into separate JS modules
- Dynamically injecting DOM content per section without reloading
- Working with loaders and plugins (CSS, HTML)

## Run it locally

```bash
git clone https://github.com/aaryan2591/restaurant-page.git
cd restaurant-page
npm install
npx webpack serve
```
