# ✅ To-Do List

A to-do list app with support for multiple projects, built with a 
modular JavaScript architecture and bundled with Webpack.

🔗 **[Live Demo](https://aaryan2591.github.io/todoList/)**

<img width="800" alt="image" src="https://github.com/user-attachments/assets/9aa0b3fa-adae-402e-b864-48a985975672" />


## Features

- Organize tasks into separate projects
- Add, edit, and manage to-do items
- Data persists across sessions (saved to local storage)
- Clean separation between logic, DOM rendering, and data storage

## Built with

- HTML
- CSS
- JavaScript (ES6 modules)
- Webpack (with separate dev/prod configs)

## What I practiced

- Structuring a project into modules (DOM, storage, projects, logic)
- Separating concerns — keeping DOM manipulation isolated from data logic
- Persisting data with local storage
- Setting up Webpack for both development and production builds

## Run it locally

```bash
git clone https://github.com/aaryan2591/todoList.git
cd todoList
npm install
npx webpack serve --config webpack.dev.js
```
